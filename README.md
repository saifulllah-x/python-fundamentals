# Python Fundamentals

Small command-line programs I built while learning Python. I'm working toward becoming a data analyst (and later a data scientist), and this repo is where I practice the basics before moving on to pandas and SQL projects.

## Concepts practiced

- Variables and data types
- Comments
- Operators and basic maths formulas
- `input()` and type casting (`float()`, `int()`)
- Formatted output with `print()`

## Programs

| File | What it does |
|------|--------------|
| `discount_calculator.py` | Calculates the final price of an item after a percentage discount |
| `employee_salary_slip.py` | Prints gross salary, tax amount and net salary from basic salary, bonus and tax % |
| `student_percentage_calculator.py` | Calculates a student's percentage from marks obtained and total marks |
| `total_sales_calculator.py` | Calculates total sales from quantity sold and price per unit |

## How to run

You need Python 3 installed. From the repo folder:

```bash
python discount_calculator.py
```

Replace the file name to run any of the other programs.

### Example

```
Discount Price Calculator
Enter Item Name: Headphones
Original Price: 2000
Discount Percentage: 15
Final Price of Headphones = 1700.0
```
